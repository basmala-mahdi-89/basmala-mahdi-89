## 🧠 How I build

1. **Model the data first** — constraints in the database, not just in the app.
2. **Secure the boundaries** — validate input, hash secrets, scope tokens, verify freshness (JWT / TOTP).
3. **Design for failure** — real-time when possible, polling when not; explicit errors instead of silent ones.
4. **Document it** — every project ships with setup steps, API notes and a troubleshooting table.
